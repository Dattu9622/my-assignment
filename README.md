# SDET Autocomplete Test Automation Suite

## Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

## Setup Instructions
1. Clone the repository: `git clone <repo-url>`
2. Install dependencies: `npm install`
3. Install Playwright browsers: `npx playwright install`

## Execution Instructions
- Run UI Tests (Headed): `npx playwright test --headed`
- Run UI Tests (Headless): `npx playwright test`
- Run API Tests: `npm run test:api`
- Generate HTML Test Report: `npx playwright show-report`
