# AI Prompts Used for SDET Practical Assignment

## Prompt 1: Test Strategy & Scenario Ranking (Task 1)
> "Act as a Senior SDET. Given an Autocomplete web form requirement, draft and rank the top 10 test scenarios based on business impact, risk level, data integrity, and usability."

## Prompt 2: Defect Analysis (Task 2)
> "Analyze the provided GET API payload response against FR-05 backend requirements for an IST user (UTC+05:30) selecting 'agile methodology'. Identify all discrepancies, root causes, and business impact."

## Prompt 3: Playwright Automation Suite (Task 4)
> "Generate a Playwright TypeScript test automation suite using the Page Object Model (POM) to cover tab navigation, suggestion filtering, input clearing via Escape, Enter key submission, and UI validation."

## Prompt 4: API Contract Automation (Task 5)
> "Create an API data contract test suite using Axios and Jest to validate JSON response schema, strict primitive types (`completed` boolean), ISO 8601 local timezone offset (`+05:30`), IETF BCP 47 locale format (`en-IN`), and negative submission edge cases."

## Prompt 5: AI Reflection & Methodology (Task 6)
> "Document the AI tools used, specific modifications made to AI-generated code (e.g., regex timezone fix, strict type assertion vs truthy check), and limitations encountered during test creation."
